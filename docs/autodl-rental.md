## 〇、先给结论（省得往下翻）

1. **Y0–Y2 的核心工作（Lean 形式化、DEM 批处理）本机 WSL2 就能跑，不租 AutoDL 也行。**
2. 若要在 Y0–Y2 跑**本地大模型做证明评测**（替代/补充 API、保证可复现），**单卡 RTX 4090（24GB）是甜点**，偶发使用月成本约 ¥60–120。
3. **A100 / H100 现在租是浪费**——它们只服务于 Y3+ 的模型训练（D3 自主定理发现），不在当前窗口。

> 两条路径可并行：**日常小评测走 API（零运维）**，**大批量/需可复现的评测走 AutoDL 本地 32B**。不必二选一。

## 一、显卡型号对照（AutoDL 2026-09）

| 型号 | 显存 | ¥/h | 在本项目中的用途 | 结论 |
| --- | --- | --- | --- | --- |
| RTX 3090 | 24GB | ¥1.32 | 本地 32B-Q4 评测、小模型推理 | ✅ 备选，更便宜 |
| **RTX 4090** | **24GB** | **¥1.88** | **Y0–Y2 本地 32B 评测甜点；Y2 批量评测** | ⭐ **首选** |
| RTX 5090 | 32GB | ¥2.78 | 更大上下文；需 PyTorch 2.8 / CUDA 12.8 | 可选 |
| RTX 3080Ti | 12GB | ¥0.98 | 仅 7B-Q4 对照（和本机 3080 同级） | 不如 3090 |
| A100 40GB | 40GB | ~¥3.45 | Y3 训练 | ❌ Y0–Y2 不用 |
| A100 80GB / A800 | 80GB | ~¥4.98 | Y3 大模型训练 | ❌ 不用 |
| H100 80GB | 80GB | ~¥9.80 | 大规模训练 | ❌ 不用 |

**为什么是 4090 而不是 3090？** 两者都是 24GB，但 4090 半精算力 165 vs 71 TFLOPS，本地跑 32B-Q4 生成快一倍多。评测要反复采样（pass@8），速度是真金白银。若预算极紧，3090 也够用，只是慢。

**为什么不用 A100？** 没训练任务时，A100 的 40/80GB 显存和 NVLink 带宽对你毫无用处，却贵 2–3 倍。等到 Y3 真要训练 D3 时再租不迟。

## 二、镜像与系统版本

**推荐镜像（创建实例时选）：**

```
PyTorch 2.5.1  +  Python 3.12  +  CUDA 12.4  +  Ubuntu 22.04
```

这是 vLLM 实测最稳的组合，跑本地 LLM 推理（Qwen2.5 / DeepSeek-R1-Distill 等）首选。

| 情况 | 镜像选择 |
| --- | --- |
| 跑本地 LLM 评测（默认） | PyTorch 2.5.1 + CUDA 12.4 + Ubuntu 22.04 |
| 若选了 RTX 5090 | 需 PyTorch **2.8.0+** / CUDA **12.8** |
| 纯 CPU 负载（Lean/GDAL/形式化） | 任意 Ubuntu 镜像均可，GPU 镜像不浪费 |

**关键澄清：** 本项目大部分负载（Lean 4 证明检查、GDAL/WhiteboxTools/RichDEM 地形计算）是 **CPU + 内存 + 磁盘 IO**，跟 GPU 镜像无关。GPU 镜像只在「本地 LLM 评测」这一片真正用到。所以即便租了 4090，也主要是用它的显存跑模型，不是用它的算力训练。

**实例启动后自行安装（CPU 侧工具链）：**

```bash
# Lean 4 工具链（elan 是 Lean 的 rustup）
curl https://elan.lean-lang.org/elan-init.sh -sSf | sh
# 地理计算
pip install gdal whiteboxtools richdem numpy scipy
# 本地推理（可选，按需）
pip install vllm transformers accelerate
```

## 三、存储容量

AutoDL 磁盘分两种，**务必分清**：

- **系统盘**：实例关机后**重置**，代码/环境在，但放这里的模型权重会丢。
- **数据盘**：持久化，挂载在 `/root/autodl-tmp`，关机保留。

| 盘 | 建议容量 | 放什么 |
| --- | --- | --- |
| 系统盘 | **50GB** | 代码、Lean 工具链、mathlib 构建产物（占数 GB）、pip 缓存 |
| 数据盘 | **200GB 起步**（多区域/全国 DEM 升 500GB） | 模型权重 + DEM 数据集 |

**容量测算：**
- DEM 数据：单区域切片 0.1–1GB；全国 30m（Copernicus GLO-30）约 40GB；多区域/多时相预算 100–300GB
- 模型权重（Q4 量化）：7B≈5GB、14B≈9GB、32B≈20GB、70B≈40GB；加上缓存与多版本，200GB 起步较从容
- 数据盘很便宜（约十几元/月/200GB），别省；**模型和 DEM 一定放数据盘**

## 四、省钱实操（很重要）

1. **「无卡模式」开机装环境**：创建实例时先选无卡模式（~¥0.10/h）装依赖、下数据、配好一切，再关机切 GPU 模式跑任务。GPU 按小时计费，装软件的时间不该花 GPU 钱。
2. **跑完即关机**：评测任务结束立刻关机，只留数据盘费。不要 24/7 挂载。
3. **设消费上限**：在账户里给 API/实例设月度上限，防 agent 或脚本跑飞。
4. **先小后大**：第一次只租 4090 跑几十次抽样验证链路通，再放大到全量，避免一上来就烧钱发现 pipeline 有 bug。

## 五、Y0–Y2 真实月成本（走本地 LLM 评测路径）

| 项 | 估算 |
| --- | --- |
| 4090 偶发使用 20–50 h/月 × ¥1.88 | ¥40–95 |
| 数据盘 200GB | ¥10–20/月 |
| **合计** | **¥60–120/月** |

对比 [`resources.md`](resources.md) 里的 API 路径（全量评测约 ¥1k–2k）：本地路径**月成本更低且完全可复现**，代价是要管理实例。实务建议：

- 日常探索、小批量抽样 → **API**（快、零运维）
- 正式全量评测、要存档可复现结果 → **AutoDL 4090 本地 32B**
